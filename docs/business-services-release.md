# 기업 서비스 확장 — 2026-09-07

사용자 요청: 정책자금뿐 아니라 기업광고·바이럴 마케팅·창업컨설팅·기업인증을 제공하는 회사로 홈페이지를 확장한다.

## 구성
- 메인: 회사 전체 소개, 4개 서비스 선택, 분야 선택 상담 폼, 사업 단계별 연결, 범용 업무 절차 및 FAQ.
- /funding: 기존 정책자금 페이지·사례의 진입 허브. 기존 기관별 URL 유지.
- /marketing, /startup: 실제 확인된 서비스 범위 안에서 상담 내용·준비 항목·비용 협의·FAQ 안내. 확인되지 않은 채널 패키지·작업물·실적을 추가하지 않음.
- /work: 현재 공개된 정책자금 사례와 분야별 업무 안내를 구분.
- /business-guide: 기존 정책자금 자료와 분야별 준비 안내 연결.
- 기업인증 페이지: 문의 분야 및 별도 견적 안내 연결.
- 신규 페이지는 정적 HTML로 관리하며 기존 정책자금 생성 스크립트의 출력 대상이 아님. 공통 스타일은 assets/business.css.
- /marketing의 기존 홈 리디렉션 제거. sitemap 및 회사 설명/구조화 데이터 업데이트.

## 상담과 분석
- service 쿼리는 general/policy/marketing/startup/certification만 허용하여 분야를 미리 선택한다.
- 기존 정책자금 페이지의 /#apply 링크는 공통 스크립트가 정책자금 선택 경로로 연결한다.
- 기존 API의 service/service_name/answers_text/diagnosis 필드에 분야를 전달하므로 API 변경 없이 메일 제목·본문에서 확인할 수 있다. 정책자금 코드는 pfm 유지.
- GA4 측정 ID G-DBGR3P6ZHD 유지. service_category를 페이지뷰 및 상담 이벤트에 추가한다.
- generate_lead는 폼 초기화 전 선택한 분야로 기록한다. 실패 재시도는 동일 요청 키를 유지하고 분야 변경 시 새 키를 사용한다.
- GA4 탐색에서 분야별 보고를 보려면 관리 → 맞춤 정의에서 이벤트 범위 맞춤 측정기준 service_category를 등록해야 한다. GA4 관리자 접근은 없어 계정 설정은 변경하지 않음.
- 마케팅 서비스 상담 신청은 광고성 메시지 수신 동의와 별개이다. consent_marketing은 false를 유지한다.
- 상담 개인정보 안내에 이용자가 선택한 서비스 분야와 웹 폼 수집을 명시하고 신규 동의 버전을 전송한다. 기존 접수 기록의 동의는 변경하지 않는다.

## 검증 및 남은 자료
- 회귀 테스트 및 서비스 선택·접수 실패·분야별 이벤트·URL·구조화 데이터 검증.
- 실제 문의 발송 없이 모의 요청으로 검증.
- 이 세션 브라우저는 화면 크기 조절 기능을 제공하지 않아 iPhone 실제 화면 검증은 별도 필요.
- 광고 운영 채널, 창업 지원 결과물, 공개 가능한 광고·창업 사례는 사용자가 제공하면 구체화 가능.
