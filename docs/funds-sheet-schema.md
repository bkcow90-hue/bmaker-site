# 자금 시트 입력 안내 (2026-09-20 결정 반영)

대상: 구글시트 '자금' 탭 → `data/funds.source.csv`. **입력은 대표가 하고, 빌더는 이미 준비돼 있다.**
열을 추가하기 전에도 사이트는 지금 그대로 동작한다(빌더가 옛 값으로 폴백).

## 1. 새 열 하나 — `가산금리`

공식 금리는 `기준금리(분기별 변동) + 가산금리`다. 고정 숫자만 적어 두면 **분기가 바뀔 때 7줄이 한꺼번에 틀어진다.**

| 자금 | `가산금리` 에 넣을 값 | `금리 방식` 열 |
|---|---|---|
| 청년고용연계자금 | `+0.0%P` | 비움 |
| 일시적경영애로자금 | `+0.0%P` | 비움 |
| 혁신성장촉진자금 · 상생성장지원자금 · 민간투자연계형매칭융자 | `+0.4%P` | 비움 |
| 소공인특화자금 · 일반경영안정자금 | `+0.6%P` | 비움 |
| 신용취약소상공인자금 | `+1.6%P` | 비움 |
| 긴급경영안정자금(일시적 경영애로) | `+0.0%P` | 비움 |
| 대환대출 | 비움 | `고정 4.50%` |
| 장애인기업지원자금 · 긴급경영안정자금(재해피해) | 비움 | `고정 2.00%` |

`가산금리` 가 비어 있으면 빌더는 `금리 방식` 값을 그대로 쓴다 — 고정금리 자금은 지금처럼 두면 된다.

## 2. 예약 행 하나 — 분기 기준금리

시트에 **행 하나를 더** 만든다. 자금ID 규칙(영소문자·숫자·하이픈)과 필수 열 검사를 통과해야 하므로 아래대로 넣는다.

| 열 | 값 |
|---|---|
| 자금ID | `base-rate` |
| 자금명 | `(기준금리)` |
| 기관 | `소상공인시장진흥공단` |
| 금리 방식 | `3.85%` ← 분기마다 이 칸만 고친다 |
| 한 줄 메모 | `2026년 3분기` |
| 공고 링크 | `https://ols.semas.or.kr/ols/man/SMAN018M/page.do` |
| 최종 확인일 | `2026-09-20` |
| **사이트 공개** | **`N`** ← 반드시 N. 페이지가 만들어지지 않는다 |
| 나머지 열 | 비움 |

## 3. 표시 결과

빌더가 계산해서 이렇게 보여준다.

```
연 4.25% (기준금리 3.85%+0.4%P, 2026년 3분기 기준)
```

고정금리 자금은 `고정 4.50%` 처럼 입력값 그대로 나온다.

## 4. 같이 채울 값 (공고 원문 기준, 확인일 2026-09-20)

출처: 소상공인시장진흥공단 「정책자금 한눈에 보기」 <https://ols.semas.or.kr/ols/man/SMAN018M/page.do>

| 자금 | 열 | 넣을 값 |
|---|---|---|
| 일시적경영애로자금 | 가산금리 | `+0.0%P` |
| 일시적경영애로자금 | 대상 요약 | `연매출 1억 4백만원 미만, 업력 7년 미만, 일시적경영애로 사유` |
| 일시적경영애로자금 | 한도 | `7천만원` |
| 소공인특화자금 | 한도 | `운전 1억원 · 시설 5억원` |
| 혁신성장촉진자금 | 한도 | `일반형 운전 1억원·시설 5억원 / 혁신형 운전 2억원·시설 10억원` |
| 재도전특별자금 | 한도 | `일반형 7천만원 / 희망형 1억원 / 도약형 2억원` |
| 상생성장지원자금 | 대상 요약 | `일반형 TOPS 1단계 / 성장형 TOPS 2단계·상생협약 플랫폼 입점 / 도약형 브랜드 점프업 선정` |
| 상생성장지원자금 | 한도 | `일반형 운전 7천만원 / 성장형 운전 1억원·시설 5억원 / 도약형 운전 2억원·시설 10억원` |
| 청년고용연계자금 | 대상 요약 | `업력 3년 미만 청년 소상공인(만39세 이하) / 상시근로자 과반수가 청년 / 최근 1년 이내 청년 1인 이상 고용·유지` |

- **한도 칸은 유형별 텍스트를 그대로 써도 된다.** 빌더는 표시만 하고 계산하지 않는다.
- 숫자 콤마는 신경 쓰지 않아도 된다 — 시트에 `7000만원` 으로 넣어도 화면에는 `7,000만원` 으로 나온다(빌더가 포맷).
- 대상·한도 문구에 `보장`·`갚` 이 들어가면 빌드가 실패한다(의도된 안전장치).

## 5. 공통 지원자격은 시트가 아니다

상시근로자 5인 미만(제조·건설·운수·광업 10인 미만)과 제외업종은 자금별 값이 아니라 공통이라,
`/funding#common` 한 곳에 두고 자금 15장에서는 한 줄 링크로 건다. 9/27 이후 `/sosangin`·`/jungsogieop` 허브에도 같은 블록을 넣는다.
