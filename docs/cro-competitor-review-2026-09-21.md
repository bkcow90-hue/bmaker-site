## 비즈니스 메이커에 적용할 내용

1. 히어로는 정책자금 유입의 핵심 질문에 답한다. 가능한 자금과 준비 순서를 검토하는 서비스임을 한 문장으로 설명한다. 정책자금 컨설팅이라는 카테고리를 유지하고, CTA는 **무료 진단 신청** 한 개로 정리했다.
2. 비용 설명은 단계별로 정확하게 둔다. 기존 규격의 비용 안내 제한은 사용자 요청에 맞춰 변경했다. 첫 버튼 아래에 **정책자금 진단·착수금·진행비 0원 / 자금 실행 시 성과 보수가 발생합니다**를 함께 표시한다. 요율·금액·산정 방식은 추정하지 않는다. 다른 서비스 전체까지 무료로 확대하지 않는다.
3. 첫 사례 구역에는 원장 집계 **385건·439억원, 2023.09~2026.08**의 기준을 함께 둔다. 이는 사용자가 지정한 이번 작업 기준이며 실제 사이트 값은 원장 빌더에서 읽어야 한다. **385건을 385명·385개 기업으로 바꾸지 않는다.** 총 승인율·고객 수·전체 공개 여부를 도출하지 않는다. 사례 링크와 최근 실제 사례가 주장의 확인 경로가 된다.
4. 히어로 다음에 사업 상황·자금 용도·기관별 준비 조건이라는 진단 항목과 선별 진행 이유를 설명하고, 그다음 원장 사례 3개를 배치했다. 낮은 가능성에 무리하게 진행을 권하지 않는다는 방향을 말하되, 모든 거절을 뒤집거나 승인을 보장하는 문장으로 바꾸지 않는다.
5. 회사 소개에서는 대표의 **영업 경력 12년**을 정확히 한정한다. 이를 정책자금 경력 12년으로 바꾸지 않는다. 직원 상담도 있으므로 대표가 모든 상담을 직접 한다고 쓰지 않는다. 민간 컨설팅 회사이며 승인은 해당 기관이 판단한다는 점을 유지한다.
6. 상담폼은 예약 목적에 맞게 이름·연락처·개인정보 동의를 기본으로 두고, 회사 사정을 과하게 입력시키지 않는다. 기존 희망 통화 시간·선택 항목을 보존한다. 정해진 업무시간에 담당자가 연락한다는 후속 안내를 실제 운영과 맞춘다.

## 측정 제안

- 주 지표: 실제 유입 세션 대비 중복·스팸을 제외한 유효 상담 신청 비율. 총 클릭이나 Cloudflare 요청 수를 방문자 수로 대신하지 않는다.
- 과정 지표: 첫 CTA 노출→클릭→폼 시작→서버 접수 성공→실제 연락 가능→상담 완료→진행 적합 판정. 폼 성공 메시지와 담당자 수신을 별도로 확인해 ‘접수됐지만 연락할 수 없는 리드’를 구분한다.
- GA4에서 기존 `generate_lead` 등 이벤트를 우선 점검한다. 필요 시 CTA 위치·카피 버전·유입 채널·기기만 기록하고 이름·전화·상담 내용을 분석 이벤트에 넣지 않는다. 중복 이벤트를 새 전환으로 집계하지 않는다.
- 초기에는 최근 충분한 기간의 모바일·데스크톱, 유료·자연검색, 주요 키워드별 기준선을 확보한다. 유입과 실제 신청 수가 없으므로 현재 전환율이나 예상 상승률은 제시할 수 없다.
- 트래픽이 충분하면 같은 기간에 동일 유입을 무작위 배분한 A/B 비교를 한다. 주 지표·최소 감지 차이·필요 표본·종료 조건은 시작 전에 정한다. 표본이 작으면 여러 안을 동시에 돌리지 말고 한 번에 핵심 가설 하나를 검토한다.
- 전후 비교만 가능하면 광고 키워드·예산·노출 기기·요일·예산 접수 시즌 변화를 함께 기록한다. 전환이 올랐다는 사실만으로 카피 효과라고 단정하지 않는다. 상담 적합률과 실제 후속 진행도 함께 본다.
- 실패·오류는 즉시 수정한다. 통계적 성과 판단은 적정 표본을 확보한 뒤 한다. 단기 클릭 상승과 장기 매출 기여는 구분한다.

## 다음 개선 우선순위 — 이번 홈페이지 CRO 적용과 구분

1. 유효 상담 측정: 버튼 클릭·접수 성공·실제 연락 가능·상담 완료·진행 적합 판정을 연결한다. 이번 테스트는 실제 메일 발송 대신 응답을 가로채 동작을 검증했다. 운영 수신 확인과 CRM 대조는 별도다.
2. 검색 상세 페이지의 설명과 내용 일치: `/cheongnyeon`은 검색 설명에서 ‘대상 3가지’를 약속하지만 본문 대상 설명은 짧다. 공식 공고를 확인한 뒤 구체적으로 보강해야 한다. 이 페이지는 이번에 수정하지 않았다.
3. 전체 사례 연결 감사: 홈페이지는 원장 기반 카드·증빙 링크를 검증했다. `/jaedan` 등 다른 상세 페이지의 숫자·지역 수·연결 사례도 같은 방식으로 대조해야 한다.
4. 사업자대출 유입: 기존 기관별·상황별 페이지를 검색 질문과 맞추고, 적합한 무료 진단으로 연결한다. 동의어·지역명만 바꾼 대량 페이지보다 실제 조건·준비·근거의 차이를 우선한다.
5. SEO/AEO/GEO는 별도 성과축이다. 홈페이지 CRO 변경만으로 일 3,000회 노출이나 플랫폼별 100클릭을 보장할 수 없다. 검색 유입과 유효 상담률을 분리해 확인한다.

### 조사 한계

이 표본은 검색 노출과 서비스 구조를 기준으로 고른 10곳이다. 방문자 수, 광고 효율, 상담 완료율, 실제 매출 등 독립 성과 자료를 확보하지 못했다. 따라서 ‘전환율이 높은 10개 사이트’라는 이름을 붙일 수 없다. 경쟁사 페이지의 금리·제도·법률·자격 설명은 사실 검증 대상이 아니며 이 보고서는 그러한 설명을 정책 안내로 재사용하지 않는다.

자동 슬라이드, 쿠키·팝업, 로딩, 애니메이션, 세션 상태에 따라 실제 사용자가 보는 화면은 다를 수 있다. 스크린샷에 보이지 않는 DOM 텍스트는 화면 노출로 확정하지 않았다. 상단 세 구역 바깥의 자료는 위치와 역할을 설명하는 보조 확인으로만 사용했고, 폼은 최종 제출까지 조사하지 않았다. 정확한 본문 글자 수·전체 CTA 수·필수 입력 수를 확인하지 못한 곳은 억지로 채우지 않았다.

저장소 `AGENTS.md`, `CLAUDE.md`, `docs/homepage-standard.md`, `.agents/product-marketing.md`를 검토했다. 과거 상품 문서의 수치·대표 단독 운영을 암시할 수 있는 내용보다 현재 사용자 조건을 우선했다. `.assetsignore`에 `docs/`가 이미 포함되어 있어 본 보고서는 기존 비공개 문서 경로에 저장된다. 이 보고서 작성 작업에서는 홈페이지 코드·배포 설정·브랜치·커밋을 변경하지 않았다.
