## AI 티 지적 (12개)
- H1 "되는지부터 봅니다" 모호 → "신청 조건부터 확인해 드립니다" + 무엇을 확인하는지 서브에 명시
- "그래서 916곳 중 계약 절반 안 됨" 인과 성립 안 함 → 삭제 또는 미계약 사유 분류 자료 있을 때만
- "따로 준비해야 받습니다" 단정 → 자금마다 인정 범위 다름, 견적서·계약 일정 확인
- "안 하는 게 세 가지" 범주 혼합(심사 주체·허위서류·과금) → 분리
- "그 해엔 넘어가도" 삭제
- 겸손 가장 자기과시(250곳/400곳) 삭제, 계약과 실행 분리
- "반은 걸러집니다" 근거 없는 숫자
- "가능성 없으면 끝납니다" → "현재 요건에 맞지 않으면 어떤 조건이 맞지 않는지 알려드립니다"
- "얽혀 있습니다/같이 봅니다" 추상 → 조건 확인 후 안내
- "이분들께 넘깁니다" → "해당 전문가를 소개합니다" (정보 전달 근거 별도)
- 2단계 폼 문구 실제 항목과 불일치 → 선택사항 명시
- 마지막 CTA 범용 → "기존 대출, 신청 자격, 준비 서류 중 궁금한 점"
- 문체 규칙(가운뎃점 개수·종결 비율·섹션마다 날짜) 자체가 부자연스러운 삽입을 유발한다는 비판. 녹음 받아쓰기도 편집 필요.
