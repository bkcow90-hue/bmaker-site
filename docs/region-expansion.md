# 도시 페이지(/region/*) 확장 기록

## 2026-10-04 — 신규 도시 추가 정지, 19개 유지 (대표 결정)

근거: `docs/wp-audit-2026-10.md` 5-5절·6-3절.

- **정지 범위:** 새 도시 페이지를 만들지 않는다(3차 후보 포함). 기존 19장은 유지하고 사실 갱신·오류 수정은 계속한다.
- **이유:** 2주 사이 사이트에 새 URL 이 몰렸다(WordPress 31편 9/21~10/1, bmaker.kr 신규 8장 9/21~9/28, 도시 19장 10/1 하루).
  도시 간 본문 유사도 상위 5쌍이 모두 경기 묶음에서 나왔고 1위(안산↔성남 0.543)가 기준 0.6 까지 0.057 남았다.

### 재개 조건 — 2026-11-01 에 판정

두 조건을 **모두** 만족하면 재개를 대표에게 제안한다.

1. GSC(bmaker.kr) 에서 `/region/*` 미색인 비율이 사이트 평균 이하. 비교 지표는 "크롤링됨 - 현재 색인 생성되지 않음" + "발견됨 - 현재 색인 생성되지 않음".
2. 안산↔성남 본문 유사도(규격 8-1 ③, 도시명 제외 5어절 자카드)가 0.6 미만을 유지. 확인 방법은 `python -m pytest -q tests/test_region.py`(0.6 초과 시 실패) + 수치 출력.

### 평택 보강 (2026-10-04)

평택은 고유 사실이 3개(최소 기준)였다. 시 자금 2행이 같은 공고(`notAncmtMgtNo=122284`)라 1건으로 세졌기 때문이다.
여기에 다른 공고 1건을 더해 4개가 됐다.

- 추가: **「2026년 평택시 중소기업 동반성장지원사업」 변경공고** — 평택시 공고 제2026-1512호(2026-04-28, 기업투자과)
  - 출처: https://www.pyeongtaek.go.kr/pyeongtaek/saeol/gosi/view.do?notAncmtMgtNo=118433&mid=0401020100 (확인일 2026-10-04)
  - 원문: "시행시기: 2026. 4. 28. ~ 2027. 3. 20. / 재원한도: 360억 / 추천자금: 운전자금, 시설자금 / 지원기간: 1년(1년 추가 연장 가능) /
    추천한도: 업체별 최대 10억원 / 이자지원율: 자동감면 1.09%(최대 1.40% 추가 감면 가능) / 신청(추천)대상: 평택시 소재 중소 제조기업 및 ESG 경영 추진 기업"
  - 원 공고 117377번(제2026-1020호, 2026-03-23)의 변경공고로, 재원 240억→360억, 자동감면 1.68%→1.09%. 현행인 변경공고를 출처로 썼다.
- **대상 주의:** 소상공인이 아니라 중소 제조기업·ESG 경영 기업 대상이다. 빌더가 공고명 기준으로 [중소기업 대상] 표시를 붙인다.
- 접수처는 본문에 없고 첨부 hwp 에만 있어 확인하지 못했다. 그래서 `data/region-intake.source.csv` 에 넣지 않았다(페이지 표기 "공고 원문 확인").
