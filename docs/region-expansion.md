## 2026-10-04 — 정지 기간 중 기존 19장 수정·목록 허브 (중간 점검 후속 B)

정지 범위(새 도시 페이지 금지)에 해당하지 않는 변경만 했다. 도시 수 19 그대로.

- **목록 허브 `/region`** (루트 `region.html`, `build_region` 생성): 도시 페이지가 아니라 목록이다. 도시 페이지의 사실(재단 지점 축약·센터·공고 수)만
  시도별로 다시 보여주고 새 사실을 쓰지 않는다. 신규 URL 은 이 1장. 정지 사유("2주 사이 새 URL 이 몰림")에 1장이 더해지는 점은 대표 확인 사항.
- **기존 19장 수정**(규격 8-1 "사실 갱신·오류 수정"과 같은 성격의 링크 보강):
  - 소상공인 대상 공고와 성격이 비슷한 소진공 자금 링크 1~2개(공고명 기준 자동, 최대 3). 고양·전주는 소상공인 대상 공고가 없어 0개.
  - "함께 보기"에 `/region`.
- 8-1 검사: `tests/test_region.py` 통과. 유사도 상위 안산↔성남 0.543 → **0.556**, 파주↔용인 0.508, 김포↔성남 0.501 — 11/1 재개 조건 2(0.6 미만)와의 여유가 0.057 → 0.044 로 줄었다.
- 대표 승인(2026-10-04, PR #27): `/region` 허브 승인. **지역 페이지를 고칠 때마다 유사도 최대값(현재 0.556, 기준 0.6)을 확인해 PR 에 적는다.**
