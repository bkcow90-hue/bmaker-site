# 김상표 대표 교육 진행 준비안

실제 출강 전 교육 대상·장소·범위를 확정한 뒤 사용하는 내부 운영안이다. 출강 이력이나 인증 자료가 아니다.

## 기본 설명 순서

1. 시작: 오늘은 승인 여부를 판정하지 않고, 공식 정보를 읽고 내 준비 순서를 정하는 시간이라고 설명한다.
2. 구분: 지원금과 상환 의무가 있는 융자, 보증기관과 은행의 역할을 구분한다. 지원금도 사업별 조건·정산·환수 기준이 있으므로 무조건 공짜라고 설명하지 않는다.
3. 공고 읽기: 교육일에 접수 상태를 확인한 공고 한 건을 사용한다. 대상, 제외 조건, 용도, 기간, 신청처, 자료를 표시한다. 날짜와 확인 출처를 강의자료에 기록한다.
4. 준비: 매출을 실제·계약·예상으로 구분하고 필요한 금액을 지출 항목과 날짜로 나눈다.
5. 사례: 아래 가상 사례로 추가 확인 질문을 함께 만든다. 승인 결과를 정답으로 제시하지 않는다.
6. 마무리: 활동지의 다음 행동 세 가지를 작성하게 한다. 개인 자료는 본인 보관이 원칙이며 공통 질문만 다룬다.

## 가상 사례 카드 A — 재고 매입이 필요한 반찬가게

설명용 가상 사례: 3년째 운영 중이며 행사에 대비해 재료와 포장재를 추가 구매하려고 한다. 매출은 계절에 따라 달라지고 기존 대출도 있다. 참가자에게 필요한 금액, 지급일, 매출 자료, 기존 월 상환액, 공고상 허용 용도를 어디에서 확인할지 묻는다. 특정 자금의 대상이라고 단정하지 않는다.

## 가상 사례 카드 B — 아직 계약 전인 신규 점포

설명용 가상 사례: 점포 계약과 설비 구매를 검토하고 있으나 사업자등록·자금 조달·오픈 일정이 확정되지 않았다. 예비창업자 신청 가능 여부, 자기자금, 계약 전 확인 항목, 지원 결과가 늦어질 때의 대안을 질문한다. 대출 승인을 전제로 계약을 권하지 않는다.

## 60 / 90 / 120분 운영

- 60분: 제도 구분 10분, 공고 읽기 15분, 준비 자료 15분, 과장 안내 구별 10분, 질문 10분.
- 90분: 역할 설명 15분, 용도 정리 20분, 활동지 20분, 가상 사례 20분, 질문·다음 행동 15분.
- 120분: 구조 설명 20분, 공고·자료 25분, 휴식 10분, 활동지 30분, 사례 토의 20분, 과제·질문 15분.

## 진행 전 준비물

교육일 확인 공고 및 공식 안내 링크, 기관 역할 설명 자료, 공개 활동지 인쇄본, 가상 사례 카드, 화면·음향 확인, 펜, 익명 공통 질문 메모. 공식 안내를 최신으로 확인하지 못한 숫자는 강의자료에 넣지 않는다.

## 질문 대응 문장

- 금액·승인 질문: “지금 정보만으로 확정할 수 없습니다. 해당 공고와 기관 심사에서 확인할 항목을 정리해드리겠습니다.”
- 개인 신용·채무 공개: “개인 정보는 여기서 공개하지 않으셔도 됩니다. 필요한 경우 공식 기관 또는 별도 상담에서 확인하세요.”
- 개별 상담 요청: “교육과 별도입니다. 원하시는 분만 문의하실 수 있고, 직접 신청도 가능합니다.”

## 전문성 보강의 다음 단계

첫 교육 후 주최 측 동의를 받은 프로그램명·일자·대상·진행 사진을 교육 사례로 기록한다. 실제 응답을 수집한 경우에만 응답자 수와 조사 방법을 함께 표기한다. 협약·강의 실적·만족도·기관 로고를 사전에 만들어 넣지 않는다.
