**보완 요청을 받았다면 새 서류부터 만들기보다, 요청한 항목·사유·제출 기한·제출 경로를 정확하게 기록하세요.** 보완 요청은 그 자체로 승인이나 최종 거절을 의미하지 않습니다. 현재 단계와 요구사항은 해당 기관 담당 안내를 기준으로 확인해야 합니다.

## 요청 원문과 해석을 분리하세요

“매출 자료 추가”라는 말을 “사업계획서 전체를 다시 작성하라”로 확대 해석하지 마세요. 안내받은 문구는 그대로 보관하고, 제출 기간·파일 형식·발급일 조건처럼 불명확한 부분만 질문으로 정리합니다. 전화 안내라면 통화 일시와 담당 창구, 확인 내용을 메모하세요.

| 요청 기록 | 준비 내용 | 확인 결과 |
|---|---|---|
| 요청 항목과 원문 | 자료명·요청 사유 | 정확한 범위를 확인했는가? |
| 제출 조건 | 기간·발급일·원본 여부·파일 형식 | 기존 자료로 대체 가능한가? |
| 준비 담당 | 대표·회계 담당·외부 담당 구분 | 누가 언제 준비하는가? |
| 제출 경로 | 공식 시스템·기관이 안내한 경로 | 수신자와 제출 방법이 맞는가? |
| 완료 기록 | 제출일·파일명·접수 여부 | 전송과 정상 접수를 구분했는가? |

## 자주 생기는 혼선을 줄이는 네 가지

1. **기간을 맞추기:** 자료마다 다른 기간이 섞였다면 어떤 기준으로 작성했는지 확인합니다.
2. **수치 기준을 맞추기:** 공급가액·세금 포함액, 확정 매출·예상 매출을 구분합니다.
3. **버전을 관리하기:** 최종본 파일명에 기준일을 표시하고 중복 제출을 피합니다.
4. **접수를 확인하기:** 업로드 완료, 제출 완료, 담당자 확인이 같은 상태라고 가정하지 않습니다.

## 설명 메모는 이렇게 작성하세요

> 요청하신 ○○자료를 첨부합니다. 대상 기간은 ○○이며, 기존 제출본과 달라진 부분은 ○○입니다. 수치 차이는 ○○기준의 차이로 확인했습니다. 추가 확인이 필요한 부분은 ○○입니다.

실제 확인하지 않은 이유를 임의로 작성하지 마세요. 숫자가 맞지 않으면 회계·세무 담당자와 사실관계를 확인하고, 원자료를 바꾸어 일치시키려 하지 않아야 합니다. 설명 메모가 원본 증빙을 대신하는지도 기관에 확인하세요.

## 기한을 맞추기 어려울 때

연장이 가능한지와 요청 방법을 마감 전에 담당 창구에 문의하세요. 문의했다고 자동으로 연장되는 것은 아닙니다. 발급이 늦어지는 이유, 준비 가능한 시점, 대체자료 검토 가능 여부를 구체적으로 전달하고 안내 결과를 남기세요.

## 자주 묻는 질문

### 서류를 많이 보내면 도움이 되나요?

요청과 무관한 자료를 무작정 늘리기보다 필요한 자료를 명확히 구분하는 편이 좋습니다. 개인정보가 과다하게 포함되지 않았는지도 확인하세요.

### 컨설팅 업체가 기관 대신 보완 여부를 결정하나요?

아닙니다. 기관의 요구사항과 심사 판단을 대신할 수 없습니다. 민간 컨설팅은 자료 정리와 준비 순서 검토를 돕는 별도 서비스입니다.
